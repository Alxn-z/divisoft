# IA y verificación — pantallas

ESTADO: PENDIENTE

No hay pantalla de «posibles coincidencias» ni carga de cédula. Un avistamiento no calcula un porcentaje.

Cuando exista, el texto debe decir posible coincidencia, nunca identificación confirmada. La cédula no se muestra en `/q/:codigo` ni en el perfil público.

Falta el proveedor y el umbral. Ver `huella-back/docs/pendientes/ia-y-verificacion.md`.
