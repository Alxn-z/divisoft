# Divisoft

Landing page basada en la referencia suministrada, construida con Next.js, TypeScript, React, CSS y Lucide.

## Desarrollo

```sh
npm install
npm run dev
```

Abre http://localhost:3000. Para generar una versión estática: `npm run build`. El resultado queda en `out/`.

La página incluye navegación responsive, detalles de servicios y formulario que descarga un resumen local. No envía correos ni almacena datos en un servidor. Para habilitar contacto real, conecta un servicio de correo o el WhatsApp de Divisoft.

Las ilustraciones se muestran como recortes CSS de la referencia en public/reference.png. Sustitúyelas por los originales para lograr fidelidad exacta y mejorar la calidad en diferentes pantallas. Los iconos se recrearon con Lucide.
