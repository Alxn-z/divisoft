# Documentación de Divisoft

Esta carpeta guarda la trazabilidad del trabajo sobre la landing. Cada cambio relevante se anota en [bitacora.md](bitacora.md), en orden cronológico, antes de dar el trabajo por cerrado.

Para dejar las consultas en PostgreSQL, sigue [ALMACENAR-CONSULTAS.md](ALMACENAR-CONSULTAS.md). El landing de Next con Supabase sigue en [BASE-DE-DATOS.md](BASE-DE-DATOS.md).

## Cómo registrar un paso

Añadir una entrada nueva al inicio de la bitácora, con esta estructura:

1. Fecha.
2. Qué se pidió.
3. Qué se hizo, en el orden en que se hizo.
4. Archivos creados, modificados o eliminados.
5. Cómo se comprobó.

No hace falta documentar pruebas descartadas ni detalles de estilo que no cambien el resultado. Sí hay que dejar escrito cualquier decisión que afecte al diseño, al comportamiento o a los archivos públicos.
